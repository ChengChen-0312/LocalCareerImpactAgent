## 项目介绍

面向求职者理解 AI 对未来工作任务的影响，设计并开发本地运行的职业分析系统。采用 React、TypeScript 和 FastAPI 构建对话式交互，支持 PDF、TXT 与音频资料输入，结合本地知识库生成未来 1–3 年、3–5 年的职业任务变化、风险、机会和行动建议。采用星形多智能体架构：Qwen3-VL-30B 负责分析与最终决策，三个共享 Qwen3-VL-4B 的审核角色分别检查证据、推理边界及语言与安全问题；通过本地 RAG 和可追溯引用为报告提供依据。项目当前处于 MVP 与稳定性优化阶段。

## 项目职责

1. 负责需求梳理、系统架构及前后端开发，构建对话、文件上传、资料抽取与确认流程，集成 PDF 文本/OCR 和本地 Whisper 语音转写。
2. 设计主模型唯一决策、子模型仅提供建议的星形协作机制，实现三个审核角色及主模型逐条处理审核意见的闭环。
3. 实现本地文档分块、FTS5 与向量混合检索、RRF 排序融合和冻结知识快照，建立报告主张与来源证据之间的可追溯关系。
4. 将长报告生成拆分为决议、主张修订和叙事生成三个阶段，使用 Pydantic/JSON Schema 约束输出，由后端确定性装配引用并校验后保存。
5. 实现本地模型进程管理、统一 Metal 推理锁、有界重试和分阶段诊断，结合真实 API 场景持续定位格式生成与最终校验问题。

## 项目成果

完成本地资料解析、RAG 检索、多智能体审核、分阶段报告生成与校验存储的核心链路。真实 API 成功场景完成 9 个处理阶段，保存 1 份通过完整校验的报告，实现 9 条审核建议与 9 条最终决议匹配，并解析同一知识快照下的 2 条引用。分阶段合成验收中，F1/F2/F3 均首轮通过，12 条主张与 43 个叙事引用完成一致性校验。保留并运行 134 项既有检查；目前继续优化长资料和复杂输入的生成稳定性，后台执行、SSE 与最终报告页面仍在后续计划中。
