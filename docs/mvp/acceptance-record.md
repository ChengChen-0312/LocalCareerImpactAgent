合计 842.804 秒、5 份报告、8 条可解析引用。五例 F2/F3 均首次通过，最终 validator 均实际执行且错误数为 0；F1 的一次失败在原有重试次数内恢复，未放宽最终规则。注入场景的已知攻击标记未进入报告；这只验证该输入，不构成全面防注入证明。

每例实际完成顺序均为：检索 → 30B 草稿 → 4B 证据审查 → 4B 边界审查 → 4B 安全审查 → 30B F1 决策 → 30B F2 修订声明 → 30B F3 报告叙述 → 最终验证与保存。每例 18 个公开运行/完成事件、9/9 完成，三组审核各 3 条建议，9 条建议与 30B 决议精确对应；原始与 F2 声明 ID 集合一致。报告所有权读取、冻结快照绑定、引用与语言检查通过。

API 场景在提取后使用确认资料夹具，因此这组结果不单独证明资料提取的完整性。实际编辑、确认和多附件体验由下方浏览器验收提供证据。

## 修正、检查与清理

- 严格 JSON 约束生成复用原有本地权重，补齐应用拥有的 ID、审核角色和有效引用范围；语义内容及采纳/拒绝仍由 30B 决定，4B 无保存权限。
- F3 使用生成阶段的数组、长度和完整单句约束；模型自行选择和归纳内容，后端不裁切或补写报告。浏览器发现的句子截断、栏目重复已修正并重新核读。
- 阶段、attempt、安全错误类别、结构位置和 token 指标持久保留；读取失败不会再次抹去模型诊断。最后一次审核绑定失败暴露了无有效重试反馈的问题，现已修复并通过最终五例验证。
- 最新产品源码的既有测试 **134 passed（1.97 秒）**；Python 编译、脚本语法、前端类型检查与构建通过。未新增或修改测试源码，11 个既有测试文件哈希保持一致。前端未变化后没有反复构建。
- 每个 API 场景及浏览器临时数据库、账户、来源、附件、会话均已清理；本轮模型/API 进程已退出。保留安全收据，不保留提示词、候选人原文、密码或推理过程。

历史 [stability-results.json](stability-results.json) 是较早的受限生成候选版本五例通过；原 Task 6F 的合成 PASS / API FAILED、后续失败及修复记录均独立保留。停止条件是最终固定 API 五例通过、核心浏览器流程通过、已有检查通过且没有新的已知阻塞问题，不是宣称模型不会再失败。
